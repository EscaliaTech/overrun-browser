# Overrun — Documentación

**Overrun** (codename interno; ver [`decisiones/BRANDING.md`](decisiones/BRANDING.md)) es un
navegador web para **desarrollo, debugging y testing**, donde las DevTools viven
en un **overlay flotante** que no le roba viewport a la página. Si es tu primera vez, empezá por
[`producto/PRODUCTO.md`](producto/PRODUCTO.md).
